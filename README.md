# Privacy Policy for Grabzo

This repository hosts the public Privacy Policy for the Grabzo mobile app (Grabzo By Mather).

The live page is at: https://<user>.github.io/grabzo-privacy/

## Publishing

The site is plain static HTML with no build step. GitHub Pages serves `index.html` from the repository root.

Enable it under: **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`**

## Note

The text here is kept in sync with the in-app policy screen at
`src/screens/policies/PrivacyPolicy.js` in the Fastkart app repository.
